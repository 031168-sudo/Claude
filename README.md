# Alfanomy (mapp)

Android-обёртка (WebView) для веб-интерфейса GPS-мониторинга `m.alfanomy.ru`.
Пакет: `ru.alfanomy.mapp`.

## Состав

- `app/src/main/assets` — веб-приложение (HTML/JS/CSS), которое грузится в WebView.
  `code.js` — минифицированный бандл клиентской логики (сборка 2015 года), правки
  в него вносятся точечно через `git diff`, без пересборки бандла из исходников
  (исходников бандла в репозитории нет).
- `app/src/main/java/ru/alfanomy/mapp` — нативная часть: `MainActivity` (WebView)
  и `MyFirebaseMessagingService` (push-уведомления через Firebase Cloud Messaging).
- `firebase-push-server-integration.md` — что нужно доделать на сервере
  (`alfanomy.ru`), чтобы push-уведомления реально отправлялись. Серверного кода
  в этом репозитории нет.
- `keystore/debug.keystore` — стандартный debug-ключ для debug-сборок.

## Сборка

CI (`.github/workflows/android.yml`) собирает APK на каждый пуш в
`main`/`master`, в ветки `release/**` и на теги `v*`, и кладёт его в артефакты сборки.

## Версии и релизы

- `main` — то, что опубликовано в магазинах. Код опубликованной версии 1.0
  сохранён в ветке `release/1.0` (от неё можно делать срочные исправления 1.x).
- Новая версия разрабатывается в ветке `release/<версия>` (например, `release/2.0`).
  Каждый пуш в неё выкладывает APK в GitHub Releases как предварительную
  (pre-release) тестовую сборку `v<версия>-test-<номер сборки>`.
- Когда версия проверена, ветка вливается в `main` через pull request, на коммит
  ставится тег `v<версия>`, и CI выкладывает финальный GitHub Release с APK.
- В RuStore и App Store CI ничего не загружает — это делается вручную.
- Номер версии (`versionName` в `app/build.gradle`, `MARKETING_VERSION` в
  `ios/project.yml`) меняется вручную; номер сборки ставит GitHub Actions.

## Проверка GPS / LBS

Веб-интерфейс (`app/src/main/assets/code.js`, копия в `ios/web/code.js`) проверяет
достоверность GPS для каждой точки и при необходимости показывает положение по LBS.
Пороги задаются в объекте `gpsCheck` в начале `code.js`:

| Параметр | Значение | Смысл |
|---|---|---|
| `staleMs` | 600000 | GPS_TIME старше SERVER_TIME больше чем на 10 мин — GPS недействителен |
| `maxGpsLbsKm` | 3 | расхождение GPS и LBS больше 3 км — признак подозрительного GPS |
| `minSatellites` | 4 | спутников меньше 4 — признак подозрительного GPS |
| `maxJumpKmh` | 200 | скорость между соседними точками больше 200 км/ч — «прыжок» |
| `minJumpKm` | 0.5 | более короткие прыжки не учитываются |
| `minSuspiciousSigns` | 2 | сколько признаков нужно, чтобы GPS считался подозрительным |
| `autoSwitchSuspicious` | true | при подозрительном GPS сразу показывать положение по LBS |

GPS недействителен, если спутников 0, координаты GPS нулевые или данные GPS
устарели. Тогда положение берётся по LBS. Если подозрительны и GPS, и LBS,
остаётся GPS с пометкой «Положение не подтверждено». Обе копии `code.js` должны
оставаться одинаковыми.

## История

Раньше проект хранился как zip-архив, который распаковывался в CI на лету —
без истории изменений исходников и без возможности осмысленного отката.
Начиная с ветки `restructure/unpack-project` источники распакованы и
версионируются обычным образом.
